# Archived Handoffs

Last updated: 2026-02-13

This folder contains historical AI pipeline handoff documents and superseded execution plans.

## Naming Convention

- `OPUS_HANDOFF_*.md`: Session handoff briefs and investigation summaries.
- `NEXT_STEPS_*.md`: Older execution plans superseded by current run-state docs.

## Header Convention

Each archived handoff in this folder uses a normalized metadata section:

- `## Archive Metadata`
- `Document Type`
- `Status`
- `Normalized On`
- `Canonical Location`
- `Current Source of Truth`

## File Registry

- `NEXT_STEPS_POST_TRAINING.md`
- `OPUS_HANDOFF_DEMUCS_DOMAIN_GAP.md`

## Current Operational Docs

For active run state and commands, use:

1. `ai-pipeline/documentation/current/ACCURACY_IMPROVEMENTS_TRACKER.md`
2. `ai-pipeline/documentation/current/OPUS_HANDOFF_SESSION3_DUAL_MODEL_ENSEMBLE.md`
3. `ai-pipeline/documentation/current/CURRENT_AI_PIPELINE_STATE.md`
