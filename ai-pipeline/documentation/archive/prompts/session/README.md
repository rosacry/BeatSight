# Archived Session Prompts

Last updated: 2026-02-13

This folder contains historical prompt documents from prior AI pipeline work sessions.

## Naming Convention

- `OPUS_*_PROMPT.md`: Archived session prompts authored for Opus/Codex continuation.
- `FILES_TO_ATTACH*.md`: Attachment/checklist helpers tied to specific historical sessions.
- Legacy variants use uppercase suffixes (for example, `_OLD`) to keep naming consistent.

## Header Convention

Each archived prompt in this folder uses a normalized metadata section:

- `## Archive Metadata`
- `Document Type`
- `Status`
- `Normalized On`
- `Canonical Location`
- `Current Source of Truth`
