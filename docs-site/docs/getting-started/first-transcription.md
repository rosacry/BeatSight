# Your First Transcription

Learn how to generate your first AI drum beatmap.

## Step 1: Upload a Song

1. Click **Upload Song** from the home page
2. Select an audio file (MP3, WAV, or FLAC)
3. Enter the song title and artist (optional but recommended)

### Supported Formats
- **MP3** - Most common, works great
- **WAV** - Lossless, best quality
- **FLAC** - Lossless compressed

### File Size Limits
- Free tier: 15 MB per file
- Premium: 50 MB per file

## Step 2: Wait for Processing

Our AI pipeline processes your song through several stages:

1. **Audio Analysis** - Detecting tempo, time signature
2. **Stem Separation** - Isolating the drum track
3. **Transcription** - Converting audio to MIDI events
4. **Post-processing** - Cleaning up and quantizing

This typically takes **2-5 minutes** depending on song length and queue.

## Step 3: Review Results

Once complete, you'll see:
- **Accuracy Score** - How confident the AI is
- **Detected Tempo** - BPM and time signature
- **Instrument Breakdown** - Kick, snare, hi-hat, etc.

## Step 4: Download or Practice

Choose your next step:
- **Download .bs file** - For use in the desktop app
- **Practice Online** - Use the web player
- **Edit** - Make corrections in the editor

## Tips for Best Results

1. **Use high-quality audio** - 320kbps MP3 or lossless
2. **Clear drum mix** - Songs with prominent drums work best
3. **Avoid live recordings** - Studio tracks are more consistent
4. **Check the tempo** - Verify the detected BPM is correct
