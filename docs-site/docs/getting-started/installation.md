# Installation

Get started with BeatSight in minutes.

## Web App

The easiest way to use BeatSight is through our web application at [beatsight.app](https://beatsight.app).

1. Create an account or sign in
2. Upload a song
3. Wait for AI processing (typically 2-5 minutes)
4. Download your beatmap or practice online

## Desktop App

For the full practice experience with audio playback:

### Windows
1. Download the latest installer from [Releases](https://github.com/rosacry/BeatSight/releases)
2. Run `BeatSight-Setup.exe`
3. Follow the installation wizard

### macOS
1. Download the `.dmg` file from [Releases](https://github.com/rosacry/BeatSight/releases)
2. Open the DMG and drag BeatSight to Applications
3. On first launch, right-click and select "Open" to bypass Gatekeeper

### Linux
```bash
# AppImage (recommended)
chmod +x BeatSight-*.AppImage
./BeatSight-*.AppImage

# Or via Flatpak
flatpak install beatsight
```

## System Requirements

| Platform | Minimum | Recommended |
|----------|---------|-------------|
| OS | Windows 10, macOS 11, Ubuntu 20.04 | Latest version |
| RAM | 4 GB | 8 GB |
| Storage | 200 MB | 500 MB |
| Audio | Any audio output device | Low-latency audio interface |
